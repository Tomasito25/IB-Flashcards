# IB-Flashcards

Flashcards de Anki para el Bachillerato Internacional (IB).

## Contenido

Mazos exportados de Anki en formato `.apkg`, organizados por asignatura:

- Matemáticas: Análisis y Enfoques (MAE) NM

Se irán añadiendo más mazos con el tiempo.

## Cómo importar un mazo en Anki

1. Descarga el archivo `.apkg` que quieras (botón **Download raw file** en GitHub).
2. Abre Anki y ve a **Archivo > Importar**.
3. Selecciona el archivo `.apkg`. El mazo aparecerá en tu lista de mazos.

También puedes hacer doble clic en el `.apkg` si Anki está instalado.

## Cómo descargar todo el repositorio

```bash
git clone https://github.com/Tomasito25/IB-Flashcards.git
```

O desde GitHub: **Code > Download ZIP**.
